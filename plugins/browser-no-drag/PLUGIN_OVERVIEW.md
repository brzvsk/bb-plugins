## What you get

- **Clickable pages.** Pages that mark parts of themselves as window drag regions, such as Linear issue pages, can be clicked, typed into and scrolled again in the BB desktop browser.
- **Nothing to configure.** No toolbar button or settings; disable the plugin to restore BB's default behavior.

## Limits

- Top-level page only; iframes and shadow roots are not changed.
- Right after a navigation, the page may stay draggable for up to half a second.
- Built on the experimental browser page API, so a future BB release may need a plugin update.

## Privacy

The plugin only adds one style element to the page. It does not read page content, send data anywhere, or need an account.
