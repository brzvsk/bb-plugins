bb's sidebar thread list with an inline title search.

## What you get

- Everything bb's own Thread list does — it is the same list, patched.
- A **Search** row under New thread: click it, type, and the list filters by thread title. Matching child threads keep their parents; collapsed groups open while you search.
- An **Include archived** toggle beside it that switches the list's existing active/archived setting.

## How it works

Layout preferences stay in bb's built-in Thread list plugin; this plugin's server forwards reads and writes to it, so both lists and `bb thread-list prefs` agree. Keep the built-in Thread list plugin enabled and choose this list under Settings → Appearance → Sidebar.
